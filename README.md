## 📲 Archivai Mobile – Intelligent Document Management, Anywhere  

**Archivai Mobile** is the Android companion app to the **Archivai System**—a cutting-edge, AI-powered Electronic Document Management System (EDMS). Developed with **Kotlin** and **Jetpack Compose**, this mobile solution enables professionals to access, manage, and search documents efficiently and securely—anytime, anywhere.

Designed for modern teams and individuals who require instant access to structured digital archives, without being tethered to a desktop environment.

---

### ✨ Key Features

- **📂 Organized Document Sections**  
  Navigate through categorized documents with a clean and intuitive interface.

- **🧠 AI-Powered Search**  
  Instantly locate documents using intelligent search capabilities, powered by machine learning.

- **📝 Secure Authentication**  
  Register and log in with confidence through robust authentication mechanisms.

- **🔔 Real-time Notifications**  
  Receive instant updates to stay informed about document activities and system alerts.

- **👤 User Profile Management**  
  Seamlessly view and update personal details in a user-friendly profile screen.

- **🚀 Smooth and Intuitive Navigation**  
  Enjoy a polished user experience with responsive transitions and a modern design language.

---

### 🛠️ Tech Stack

- **Kotlin** – A modern and expressive language tailored for Android development.  
- **Jetpack Compose** – A powerful declarative UI toolkit for building dynamic and responsive interfaces.  
- **MVVM Architecture** – Ensures a clear separation of concerns for scalable and maintainable code.  
- **Retrofit** – Simplifies and optimizes network communication with the backend services.  
- **Hilt** – Efficient dependency injection to promote modular, testable, and robust code structure.
